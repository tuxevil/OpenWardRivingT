# ADR template

- **Status:** Proposed | Accepted | Superseded by [NNNN-…](NNNN-…)
- **Date:** YYYY-MM-DD
- **Deciders:** maintainer handle(s)

## Context

What is the issue or opportunity? What forces are at play? Reference
the relevant files, endpoints, or workflows. Keep it concrete — link to
code by `path:line` and to docs by relative path.

## Decision

What did we choose? State it in the imperative ("We do X", "We adopt
Y"). One paragraph is usually enough.

## Consequences

What becomes easier? What becomes harder? What trade-offs are we
accepting? Note both positive and negative consequences, and list any
follow-up work the decision creates.
